blukii Hub Change Log
=====================


Version 3.0.9.1
------------------

New features:

* Improved password fields protection on configuration website

* Configuration access protection of option **Show WLAN Credentials only**

* Improve fast push interval request stability


Version 3.0.8.4
------------------

New features:

* Show local IP in blukii Manager

* Caching of failed requests caused of: ensure all requests received by server


Version 3.0.7.8
------------------

New features:

* Payload JSON format 2.0 (size optimized)

* Data processing option **Life Monitoring**: Push even if no packets found

* New data type **Special Frame**

* Configuration access visibility option **Show WLAN Credentials only** 

* WLAN network selection in access point mode

* blukii SmartBeacon configuration by server


Version 3.0.4.4
------------------

New features:

* Configuration access modes (timeout and password)

* Add local IP to website and JSON payload

* Support of Hardware 3000-002


Version 3.0.3.8
------------------
First published version.

Features:

* Configuration via local website

* WLAN support (WPA, WPA2, WPA2 Enterprise)

* blukii Data Types selection

* Push interval

* Data transfer to server
    * RESTful data requests
    * Authentication selection
    * Defined JSON payload format

* Remote OTA Update via blukii Manager

* Log settings

* Support of Hardware 3000-001
